# 수집 경로 검증 결과 (타이머 시작 전, 2026-08-20)

> 타이머 중에 발견하면 각각 5~15분씩 날아갈 함정들. **미리 다 뚫어놨음.**

## ✅ 1. 탐색 — 네이버 블로그 검색 페이지는 그냥 읽힌다

```
https://search.naver.com/search.naver?where=blog&query=<검색어 URL인코딩>
```
- 브라우저 UA 필요. HTTP 200, ~880KB
- 정규식 `https?://blog\.naver\.com/[A-Za-z0-9_-]+/\d+` 로 **포스트 URL 25개 추출됨**
- **검색 API 없이 탐색 가능** ← 네이버 검색 API 가 신규 등록에서 사라진 것의 우회

## 🔴 2. 본문 — 직접 URL 은 껍데기다 (핵심 함정)

| 방식 | 결과 |
|---|---|
| `blog.naver.com/{id}/{logNo}` | **2.8KB, 한글 22자** — iframe 껍데기뿐 ❌ |
| `blog.naver.com/PostView.naver?blogId={id}&logNo={logNo}&redirect=Dlog&widgetTypeCall=true&directAccess=false` | **263KB, 한글 5,949자** ✅ |

→ 검색 결과 URL 을 **PostView 엔드포인트로 재작성**해야 본문이 온다.

## ✅ 3. 파싱 — SmartEditor ONE 문단 셀렉터

```python
re.findall(r'<p class="se-text-paragraph[^"]*"[^>]*>(.*?)</p>', html, re.S)
```
- 검증: 126문단 → 비어있지 않은 76문단 → 2,716자(한글 1,977자)
- `se-main-container` 통짜 정규식은 중첩 때문에 **제목만 잡힘**. 문단 단위로 갈 것
- `&nbsp;` 와 제로폭 문자(U+200B) 제거 필요

## 🔴 4. 데이터 특성 — 검색 결과의 상당수가 후기가 아니라 광고

표본 10건 (`뷰성형외과 후기` 검색 결과 상위):

| 구분 | 건수 |
|---|---|
| **명시적 대가성/광고 표지 포함** (`협찬`·`광고`·`대가를`) | **4 / 10 (40%)** |
| 표지 없음 | 6 / 10 |

**표지 없는 쪽이 더 위험하다.** 예: `ring760/224137593127` 은 대가성 표지가 **없는데도**
병원 화법("…뷰성형외과에서 전하여 드립니다")으로 쓰인 SEO 광고글. 환자 후기가 아님.

→ **키워드로 잡히는 건 정직하게 밝힌 40% 뿐.** 안 밝힌 건 **문체로만** 판별 가능
→ 한국 표시광고법·추천보증 심사지침상 **미표시 대가성 콘텐츠는 위법**
→ 그대로 번역해 올리면 **병원 광고를 환자 증언으로 파는 것.** 의료 결정에 쓰이는 정보라 실제 해가 됨

### 그래서 파이프라인에 반드시 있어야 하는 단계
1. **대가성 표지 탐지** (키워드) — 정직한 광고 걸러냄
2. **화법/문체 분류** (에이전트) — 미표시 광고 탐지. *병원 1인칭인가, 환자 경험 서술인가*
3. **판정을 버리지 말고 라벨로 보존** — `disclosed_ad` / `suspected_marketing` / `patient_report`
   → 버리면 데이터 손실, 섞으면 신뢰 붕괴. **dedup 이 아니라 trust 축에서 처리**

## 검증된 파이프라인 골격

```
search(clinic_ko + " 후기")        # 공개 검색, API 불필요
  → extract blog.naver.com/{id}/{logNo}
  → rewrite → PostView.naver?blogId=&logNo=
  → parse se-text-paragraph
  → [에이전트] 광고/후기 분류        ← 여기가 판단 단계
  → [에이전트] 번역 + 시술용어 정규화
  → dedupe (배리어 — 전체 필요)
  → [에이전트] 클리닉 정규화 + 신뢰 판정
  → publish → ./deploy.sh
```
